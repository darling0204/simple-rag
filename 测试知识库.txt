AI Agent 产品测试知识库

产品名称：Nova Agent

Nova Agent 是一个面向企业内部知识问答的 AI Agent 系统。

目前系统支持三种工具：知识库搜索工具、计算器工具和天气查询工具。

知识库搜索工具的名称为 search_knowledge，主要用于查询企业内部文档。

计算器工具的名称为 calculator，主要用于执行数学计算。

天气查询工具的名称为 get_weather，主要用于查询指定城市的天气信息。

当用户询问企业内部知识时，Agent 应该优先使用知识库搜索工具。

当用户提出数学计算问题时，Agent 应该使用计算器工具。

当用户询问天气时，Agent 应该使用天气查询工具。

如果一个问题同时涉及企业内部知识和数学计算，Agent 可以先查询知识库，再使用计算器完成计算。

Nova Agent 当前支持 TXT、PDF 和 Markdown 三种文档格式。

单个上传文件的最大大小为 20MB。

知识库检索使用向量相似度进行匹配。

系统默认返回最相关的 5 个文本片段。

如果知识库中没有用户询问的信息，Agent 不应该自行编造答案，而应该明确说明当前知识库没有相关信息。

系统支持多轮对话，并且最多保存最近 10 条历史消息。

用户登录采用 JWT 进行身份认证。

Access Token 默认有效期为 60 分钟。

Refresh Token 用于获取新的 Access Token。

企业管理员可以创建、删除和修改知识库。

普通用户只能查看自己有权限访问的知识库。

Nova Agent 的前端采用 React 和 TypeScript 开发。

后端采用 Python 和 FastAPI 开发。

向量数据库采用 FAISS。

关系型数据采用 SQLite。

大语言模型使用 DeepSeek。

系统目前部署在企业内部服务器上，不支持公网直接访问。
